Evaluation v1 — two runs, 33 samples

Version label: Evaluation v1 — two end-to-end runs, 33-sample cohort. One Nextflow workflow (main.nf) processes the ENA study PRJNA234495 E. coli K-12 cohort (reference NC_000913.3) through fetch (MD5-verified), a read-pair sanitize stage, FastQC/fastp, BWA-MEM alignment, per-sample QC gates, bcftools calling and a cohort report. Gates are fixed before the run: mean coverage ≥ 10.0×, reads mapped ≥ 80%, Q30 bases ≥ 70%. A sample that fails a gate has its BAM removed inside the gate step and never reaches calling. The evaluation ran the identical 33-sample sheet twice, in fully separate work and output directories — run 2 in an isolated launch directory, so no task result could be reused from run 1's cache — with the locked environment in environment-explicit.txt.

Reproducibility

  • Cohort reports byte-identical between run 1 and run 2 — MD5 822aad36… for both.
  • Per-sample variant tables: 27 of 27 byte-identical.
  • Sanitize statistics identical in both runs: 27,175,960 read pairs processed, 27,071,276 kept, 104,684 corrupt pairs dropped (0.39%).
  • Gate decisions and metrics identical for all 33 samples, including all six stops.
