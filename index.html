How it works

Data in. Pipelines run. Evidence out.

One standard across every product: measure first, publish the result with its limits, and never let a confident-sounding answer outrun its evidence.

01 · Data in

Real data, real scale — thousands of variants, dozens of sequencing runs, full task suites. No toy demonstrations.

02 · Pipelines run

Governed, reproducible runs with a frozen test set, so a result can be re-checked instead of merely believed.

03 · Evidence out

Every claim cites its source, or the system declines. Calibration is reported alongside accuracy, because both matter.

The rule behind everything here is cite-or-decline. A variant report is only as good as the evidence it can point to. When the evidence is thin, declining is the correct answer — and it is the answer the Variant Evidence Agent gives 17,391 times out of 27,748.

Calibration is reported alongside discrimination: the final model reaches AUROC 0.970 with a calibration error of ECE 0.025, measured on the 10,357 variants it scored out of the 27,748 in the frozen temporal test set — a test set the model never trained on.

Validation

Tested on the future, not the training set

Most variant tools are tested on data they were tuned on. Omevra’s headline numbers come from a temporal split: the model was fitted on ClinVar as frozen in January 2024, and tested on variants whose classifications were made or changed after that freeze — a test set the model never trained on. A temporal split cannot leak the way a random split does.

AUROC 0.970, measured on the 10,357 variants the model scored out of the 27,748-variant temporal test set — with a calibration error of ECE 0.025 on the same scored variants: when the model says 0.80, it is right about 80% of the time.

Coverage is 37.3%. The model scores the missense variants that carry predictor scores and declines the rest — most of them non-missense variants with no predictor score at all — rather than inventing a probability.

Every claim in an evidence report cites the record retrieved for it. Where the evidence is too thin to support a claim, the system declines — and the decline is shown as a decline, never dressed up as a result. Cite-or-decline.

Use cases

Built for the VUS problem

Three ways research teams use calibrated, cited variant evidence — and the limits of each, stated plainly.

Rare-disease research

An evidence pack for each candidate variant: a calibrated probability where the evidence supports one, a citation behind every claim, and an explicit decline where it does not — so a researcher starts from the evidence, not from a blank search page.

Cohort VUS triage

Score a batch list in one run: the borderline band (0.40–0.60) surfaces for human review first, and declines stay visible in the dashboard and the exports — the whole cohort triaged, including the honest “not enough evidence” answers.

Biotech target validation

Gene-level evidence summaries from the variant record, and reproducible pipeline runs through the Atlas — the same code, run again, returning byte-identical results that a reviewer can verify.
