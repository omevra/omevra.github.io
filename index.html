Variant Evidence Agent

What it does

Tested the way time actually runs

The system trains on ClinVar classifications frozen at January 2024 and is evaluated only on variants of uncertain significance that were reclassified after that freeze — a strictly temporal test, not a random split, so no variant is credited for evidence that only existed later.

Probabilities that mean what they say

Predictions are calibrated, so a “90% pathogenic” output should be right about 90% of the time. On the post-freeze test set the final model reaches AUROC 0.968 with calibration error (ECE) 0.023 — and the calibration record, including where it fails, is published inside the system.

Evidence reports — cited, or declined

For each variant, the agent retrieves the records behind a call and writes an evidence summary in which every claim is cited. Where the evidence is not there, it declines. On the test set it reports on 10,373 variants (37.4%) and declines 17,375.

Open it and look inside

Inside the full system: look up any test-set variant and read its stored report, compare eight model variants on interactive calibration and ROC charts, read the validation dossier — design, performance including the worst genes, failure modes, oversight — and the honest limits, stated in the system’s own terms.

Evidra · Product two

web-agent

An autonomous agent that operates web interfaces end to end — and publishes exactly how often it succeeds.

web-agent runs real browser tasks in a live headless Chromium session. Its loop is observe → act → verify → recover: take a fresh snapshot of the page, act on it, verify the result — and when the page fights back, re-ground and recover instead of failing silently.

The evaluation is an ablation, run both ways on the same 36 tasks. With recovery on, it passes all 36. With recovery switched off, the same agent passes 27 — and every one of the 9 adversarial tasks fails. The difference is the recovery system, measured, not asserted.

Evidra · Product four

NGS Pipeline Atlas

A reproducible bacterial whole-genome pipeline — paired-end reads in, QC-gated variant calls out — executed twice to prove it reproduces.

A Nextflow pipeline processes a public E. coli cohort (ENA PRJNA234495) through fetch, a read-pair sanitize stage, FastQC and fastp, BWA-MEM alignment, per-sample QC gates, bcftools calling and a cohort report. The gates are real: a sample that fails has its BAM removed and never reaches calling — including one deliberately bad input planted in the samplesheet.

Run end to end twice, in separate directories with nothing reused, the two runs produced byte-identical cohort reports and identical variant tables for every passed sample.

Evidra · Product five

Multi-Agent Evidence

Three cooperating agents for genetic-variant evidence work — Retriever, Synthesiser, Critic — measured against the single-agent baseline they have to beat.

A LangGraph state graph splits Build 1's evidence work three ways: a deterministic Retriever assembles the evidence packet, a Synthesiser drafts cited claims from it, and a Critic checks every claim against the packet, with a deterministic finalise step enforcing the cite-or-decline gate in code. The baseline is the same model, the same packet, the same task text, in one pass.

Over a fixed 36 variants the two systems tie on every quality axis — citation accuracy 1.00 vs 1.00 after audit, completeness 1.00 vs 1.00, decline correctness 36/36 both — and the multi-agent system costs 2.7× the tokens and latency to get there. The tie is published as the finding; what the critic loop demonstrably did — 47 rounds, 16 rejections, a sabotaged claim caught — is published with it.
