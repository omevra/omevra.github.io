Evaluation v1 — temporal split, train frozen Jan 2024

Version label: Evaluation v1 — temporal split, train frozen Jan 2024. This page is the proof record for the Variant Evidence Agent: the protocol in full, every versioned result, and the files behind them.

All data is open and pinned by date. ClinVar classifications are frozen at the Jan 2024 cutoff: the cutoff snapshot held 2,366,650 GRCh38 rows (the current snapshot holds 4,578,190). The train set is the 1,103,657 variants labelled at the cutoff (240,752 pathogenic, 862,905 benign), frozen. The test set is only the 27,748 variants that were of uncertain significance at the cutoff and have since been reclassified (8,856 pathogenic, 18,892 benign) — no test label existed at train time. Features are joined as of the cutoff where the source allows dating; calibration maps are fitted on train data only (an 80/20 seed-11 split, isotonic fitted on the train holdout) and judged on the untouched test set. The near-duplicate guard removes test rows sharing gene + name with train; it removed 0 rows in this build. Full design: Temporal evaluation · Calibration.

Why random splits leak

A variant reclassified after the cutoff was often reclassified using the same predictor scores that appear as features. A random split puts that variant — or its near-duplicates — in both train and test, so the model is graded on evidence it has already seen. The temporal split removes the direct leak. The caveat is stated in the split report itself: post-cutoff reclassifications are themselves partly predictor-influenced, so measured performance is performance against real-world reclassification practice, not against predictor-free ground truth.

The scored subset

The predictors are missense-only precomputed scores, so the model serves a scored subset of the test set: 10,373 of 27,748 test variants carry an AlphaMissense score (37.4%), 10,357 carry both AlphaMissense and REVEL. The adopted final model (GBM+R) requires both scores, so the agent summarises 10,357 variants and declines 17,391. Every metric below names its n. The agent summarises exactly the variants it can score and support with cited evidence, and declines the rest — a decline is a designed output, not an error.

Summarise or decline — the before/after record

The agent's contract is cite-or-decline: a summary is issued only where the evidence supports one, and every other variant is declined individually. On the temporal test set the live split is 10,357 summarised (37.3%) against 17,391 declined (62.7%). Coverage is the binding limit: the model scores 37.3% of the test set — the missense variants with predictor scores — and most of the declined remainder are non-missense variants with no predictor score at all. Extending coverage to splice and non-coding variants is next on the roadmap.

Before / after — the 2026-10-26 model adoption

Before — Model 2 served (logistic, AlphaMissense + gene prior). The output split the live app actually served until 2026-10-26, as published in docs/validation-dossier.md §4–§5 before the addendum:

After — GBM+R live (gradient boosting + REVEL + isotonic; Evaluation v3 model adoption, 2026-10-26). The cite-or-decline rule did not change (MIN_EVIDENCE = 3, unchanged). The counts shifted only because GBM+R requires a REVEL score in addition to AlphaMissense: 16 variants carry an AlphaMissense score but no REVEL score, so they no longer receive a model probability and are declined like every other unscored variant:
