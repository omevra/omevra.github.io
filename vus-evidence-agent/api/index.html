Variant Evidence Agent — API

The public API: endpoints, enforced bounds, and copyable examples with real responses.

Base URL and framing

Base URL: https://evidra-variant-evidence-agent.hf.space. Responses are JSON. This is a research-use API over a frozen scored universe: the 27,748 variants of the temporal test set (train frozen Jan 2024), of which 10,357 are summarised with cited evidence and 17,391 are declined. The served model is GBM+R (gradient boosting + REVEL + isotonic), adopted 2026-10-26 — /api/meta reports it as model version “v3 gradient boosting (GBM+R)”. A variant outside the universe returns “not found” rather than an invented answer — the API never fabricates a score or a summary. Live-evidence lookups (ClinVar / gnomAD / PubMed, retrieved at request time) are labelled as live context and carry no model score.

Not for clinical use.

Enforced bounds

  • Batch: at most 500 variants per batch.
  • Inline batch (in the page): at most 25 variants.
  • At most 4 concurrent batch jobs — beyond that, the API returns 429.
  • File upload: at most 2 MB (.txt, .csv or .tsv).
  • At most 50 out-of-universe live lookups per batch — beyond that, remaining out-of-universe variants are reported as live-evidence not run, never guessed.
